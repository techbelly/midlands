# gezira

The Nile source of [gezira](https://github.com/damelang/gezira), by Dan Amelang:
the 2D vector graphics library from the VPRI STEPS project. Copyright
Dan Amelang, MIT licence ([LICENSE](LICENSE)).

About 600 lines in eight files: the types, Bézier curves, strokes (caps and
joins), rasterization, textures and gradients, compositing and filters.

The files are copied unmodified from upstream commit `9f3e684`. umgeni
compiles them as they are; nothing in midlands edits them.
