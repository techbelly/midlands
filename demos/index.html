Umgeni — text rendered by a compiled Nile pipeline

string → glyph outlines (TrueType's quadratic curves are exactly gezira's beziers) → Reverse → WordWidths → Reverse → LayoutGlyphs → TransformBeziers → ClipBeziers → Rasterize, all compiled from Nile source. Word wrapping happens in Nile: running backwards over the text tells each word's first letter how wide the word is. Colour emoji (Twemoji, CC-BY 4.0) are stacks of coloured outline layers — each layer is rasterized by the same pipeline and composited in order. Drop any .ttf onto the page to set the text in it.
