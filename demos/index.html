Text

A paragraph laid out, rasterized and painted by Nile: glyph outlines in, pixels out.




  The host reads the font and turns each character into its outline beziers
  (TrueType's quadratic curves are exactly gezira's beziers), then writes the
  painted pixels. Words wrap in Nile: WordWidths runs over the text
  backwards, so each word's first glyph knows the word's width. A colour emoji
  is a stack of coloured outline layers, painted in order. On the GPU,
  Rasterize2 (the same rasterizer, written with declared scans) is
  lowered to WGSL.



How to use: edit the text, drag the size, or pick a font;
  drop a .ttf file onto the page to set the text in it. The renderer
  menu switches between the CPU and the GPU.
